# Цифровой пропуск сотрудника: прототип

Интерактивный прототип: экран блокировки с пушем → главная → профиль → «Мой пропуск» с 3D-пропуском на стропе и шторкой «Данные сотрудника».

Весь прототип в одном файле `index.html` (three.js и rapier внутри). Открывается в любом браузере; на компьютере показывает рамку телефона, на телефоне занимает весь экран.

## Варианты фона экрана «Мой пропуск»

Фон переключается параметром в адресе: `#open=pass&bg=N` (сразу открывает экран пропуска).

| bg | Фон | Цвет из Bulaq |
|---|---|---|
| 1 | Серый, как сейчас | Background/Page `#F2F2F2` |
| 2 | Мятный | Background/Accent Soft `#E7F8EA` |
| 3 | Серый → мятный | Page → Accent Soft, градиент |
| 4 | Орнамент сверху | орнамент шапки пропуска на Accent Soft |
| 5 | Тёмно-зелёный | Accent Soft, тёмная тема `#1D4E2E` |
| 6 | Графит | Background/Inverse `#272727` |
